本格的な3Dボクセル世界で、**完全無限マップ**、**サバイバルモード**、**クリエイティブモード**、**多種多様な全種類のブロック・アイテム**、そして**独自のオリジナル超能力アイテム＆ブロック**を搭載した本格マインクラフト系Windowsネイティブアプリケーションです。

---

## 🎮 主な特徴

### 1. ♾️ 完全無限マップ (No World Border / Infinite Voxel World)
- **マップ制限・見えない壁は一切なし**。どこまでも正負の無限大へ自由に探検できます。
- シンプレックスノイズによる多層プロシージャルバイオーム生成（平原、森林、砂漠、山岳、そしてレアな神秘の**アストラルバイオーム**、立体洞窟ネットワーク）。
- **動的チャンクストリーミング & メモリ自動アンロード**: プレイヤーが何十万ブロック進んでも、遠方のメッシュは自動解放され、常に安定した60FPSを維持します。

### 2. ⚔️ 本格サバイバルモード (Survival Mode)
- **体力（20HP / 10ハート）** & **空腹度（20Food / 10肉）** システム。
- 落下ダメージ（水面着地やグラビティブーツで無効化可能）。
- 水中酸素ゲージ（溺れ判定）。
- ツール適正（ツルハシ、斧、シャベル）に応じた採掘速度と耐久度。
- ブロック破壊時の3Dアイテムドロップ＆磁石吸引。
- **昼夜サイクル & 敵モブスポーン**: 夜になるとゾンビ、スケルトン、クリーパー（シューッと自爆）、牛、そしてオリジナルモンスター**「アストラルファントム」**が出現！

### 3. 🏗️ クリエイティブモード (Creative Mode)
- **飛行機能**: Spaceキー2連打で空中浮遊・上昇・下降・超高速移動。
- **一撃破壊**: ブロックを瞬時に破壊。
- **全種類アイテムカタログ**: クリエイティブパレットから全種類のブロック・アイテムを自由に取り出し可能。
- 無敵モード（ダメージ無効）。

### 4. 🪓 クラフト・かまど・チェスト
- **2x2 インベントリクラフト**（'E'キー）。
- **3x3 作業台クラフト**（ツルハシ、剣、斧、シャベル、防具、各種ブロック、オリジナルアイテム）。
- **かまど製錬**（鉄鉱石・金鉱石の製錬、肉の調理など）。
- **チェスト保管庫**（アイテム収納）。

## 🕹️ 操作方法 (Controls)

| キー | 動作 |
| :--- | :--- |
| **W, A, S, D** | 前後左右移動 |
| **マウス移動** | 視点移動 (FPS視点) |
| **Space** | ジャンプ / 水中浮上 (クリエイティブ時は2連打で飛行切替) |
| **Ctrl** | ダッシュ (スプリント) |
| **Shift** | しゃがみ / 飛行中下降 |
| **左クリック** | 攻撃 / ブロック採掘 (長押し) |
| **右クリック** | ブロック設置 / アイテム使用 / 特殊能力発動 (アストラル斬撃・レーザー掘削・ワープ) |
| **1 〜 9 / ホイール** | ホットバースロット切替 |
| **E** | インベントリ / クラフト画面開閉 |
| **T または /** | チャット / コマンド入力画面 (`/gamemode`, `/time set`, `/give` 等) |
| **F3** | デバッグ情報表示 (XYZ座標、チャンク、FPSなど) |
| **F11** | フルスクリーン切替 |
| **Esc** | 一時停止メニュー (ポーズ / セーブ / モード切替) |

## 🚀 起動方法 (Windows Application)

### 方法1: リリースZIPから（最も簡単！）
1. GitHubの [Releases](https://github.com/youyouboydragonOfficial/NovaCraft/releases) から `NovaCraft-Windows-v1.0.0.zip` をダウンロード。
2. ZIPを解凍。
3. `NovaCraft.exe` または `NovaCraftLauncher.exe`（または `Play-NovaCraft.bat`）をダブルクリックで即起動！

### 方法2: ソースコードからビルド
```bash
git clone https://github.com/youyouboydragonOfficial/NovaCraft.git
cd NovaCraft/NovaCraftApp
dotnet publish -c Release -o publish_fx
```

## 💾 ワールドセーブ
- 30秒ごとに自動セーブ（LocalStorage）。
- Escメニューから「ワールドエクスポート (JSON保存)」を押すと、ワールドデータをJSONファイルとしてダウンロード・バックアップ可能。
- 「ワールドインポート」でいつでも好きなワールドを復元できます。
